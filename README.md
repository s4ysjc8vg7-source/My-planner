# MyPlanner v4
PWA-версия MyPlanner для GitHub Pages.

Основные блоки: задачи, день/неделя/месяц, повторения, Фокус, статистика, заметки с разделами и вложениями, группы, оформление, локальный экспорт/импорт и напоминания.

Данные хранятся локально в браузере. Надёжные фоновые push-уведомления на iPhone без серверной части PWA не гарантируются.
