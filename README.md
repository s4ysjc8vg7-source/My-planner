# MyPlanner V27 — исправления интерфейса и Фокуса

Обновление поверх V26.

- В карточке редактирования поле «Цвет задачи» и образец цвета расположены в одной строке; лишняя область под ними убрана.
- В компактных карточках Фокуса и Недели снова видны время задачи и значок/название группы.
- Настройка количества задач Фокуса применяется к списку: 3, 5, 7, 10 или без ограничения.
- При изменении сортировки Недели запоминаются раскрытые дни.
- Подправлена синхронизация повторяющихся задач при пересоздании будущих экземпляров, сохраняя поля исходной задачи и её статус исходной, а не сгенерированной.
- В заметках удаление расположено в строках элементов; дата создания папки показывается в строке заголовка, а повторная стрелка справа убрана.
- Добавлена дата создания для новых папок заметок.
- Версия кэша PWA обновлена до V27.

Архив содержит только изменённые файлы: `app.js`, `styles.css`, `index.html`, `sw.js`. Иконки не включены, чтобы не менять установленную иконку.

Статическая проверка JavaScript выполнена. Функциональные сценарии и уведомления необходимо проверить на устройстве после публикации; гарантированная работа напоминаний в фоне PWA не заявляется.
