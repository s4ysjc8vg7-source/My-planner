# MyPlanner V29

Полный комплект исходных файлов MyPlanner для размещения в корне репозитория GitHub Pages.

Файлы: `index.html`, `app.js`, `styles.css`, `sw.js`, `manifest.webmanifest`.
Иконки намеренно не включены — сохраните существующие `icon-192.png` и `icon-512.png` в репозитории.

После загрузки файлов в ветку `main` приложение обновится при следующем открытии/обновлении. Данные задач и заметок хранятся локально в браузере; перед обновлением рекомендуется экспортировать резервную копию в настройках.

V29 включает исправление выбора времени напоминания для задач на весь день и сохранение раскрытых дней недели при переходе между разделами; изменения оформления заметок сохранены. Уведомления и звук в фоне на iOS зависят от разрешений и ограничений браузера/PWA.
