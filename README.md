# MyPlanner V23
Обновление на базе V22.

Изменения: цвет задачи можно выбрать в карточке редактирования; карточка получает выбранный цвет либо цвет своей группы. В настройке группы отображается предпросмотр выбранного цвета и кнопка «Сохранить и применить». Добавлен выбор сортировки для Недели и Фокуса: по времени, названию или группе. Добавлено раскрытие вложенных папок заметок на месте и удаление папок/элементов с подтверждением.

Сохранены периоды Фокуса (Сегодня, 3 дня, Неделя), сворачиваемые дни недели и похвала через 15 секунд.

Архив содержит только файлы приложения; иконки намеренно не включены. Необходимо проверить работу на iPhone после публикации.
