# MyPlanner FINAL
Финальная PWA-сборка MyPlanner для iPhone Safari.
Данные планировщика сохраняются локально на устройстве; GitHub хранит файлы приложения, а не пользовательские записи.
Возможности: день/неделя/месяц, быстрый ввод, группы, приоритеты, повторения, поиск, фильтры, массовые действия, заметки и вложения, фокус, похвала, серии, достижения, статистика, экспорт/импорт резервной копии и веб-уведомления с ограничениями Safari/PWA.
